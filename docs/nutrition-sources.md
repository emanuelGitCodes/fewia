# Nutrition sources

These values are representative recipe ingredient estimates from USDA FoodData Central.
The catalog stores energy, protein, fat, carbohydrate, and sodium per 100 g.
The macro UI excludes micronutrients.
The catalog still stores sodium from the same USDA rows.
These estimates MUST NOT be used as a medical, allergy, or safety claim.
No nutrient in this catalog is a model-invented value.

## Preparation states

Rice, pasta, and lentils use dry USDA rows.
Chicken breast, eggs, and russet potato use raw USDA rows.
Black beans and chickpeas use cooked, boiled, unsalted USDA rows as an approximation for drained beans.
Mixed vegetables use frozen, unprepared USDA rows.
Oat milk uses unsweetened, plain, refrigerated Foundation data.

## USDA edible portions

USDA lists a large egg edible portion as 50 g.
USDA lists a corn tortilla edible portion as 24 g.
USDA lists a medium russet potato edible portion as 213 g.
Different actual sizes and preparation methods change the nutrients.
