# Agent catalog scope correction

## 2026-10-03

Decision [0017](../decisions/0017-forty-meal-catalog.md) is accepted and amends [`.codex/project-context.md`](../../.codex/project-context.md). Both set the supported catalog at 40 meals. This scope takes precedence over stale ten-meal wording in agent roles.

During benchmark documentation work, the docs writer treated the stale wording as a separate ten-meal release boundary. The accepted project scope does not set that boundary.

Meal requests remain limited to one to three meals and one to eight servings per meal.

The writer sandbox blocked edits to the canonical role files. The coordinator
applied the bounded catalog wording correction to those protected files.
Role models, permissions, ownership, and security rules remain unchanged.
